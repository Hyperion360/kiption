### Added
- Site owners can now edit the words the archive shows. A new "Site text" page in the admin menu lists every interface string by group, with search. Change a string, save, and the new wording appears everywhere it is used.
- Owners can add languages, translate them in the same editor, and export or import a language as a JSON file.
- Site settings has a new default language choice, used for visitors who have not picked one.
- Text with markup, or with a placeholder missing or added, is rejected with a plain message before it is saved.

### Changed
- Error messages such as "Page not found" and form validation notes now come from the language pack, so they can be edited and translated like the rest.
